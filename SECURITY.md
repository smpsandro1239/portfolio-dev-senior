# Política de segurança

## Versões suportadas

As correções são aplicadas prioritariamente à versão publicada a partir da branch `main`.

## Reportar uma vulnerabilidade

Não publiques credenciais, tokens, dados pessoais ou detalhes exploráveis numa issue pública.

Se o GitHub apresentar a opção **Report a vulnerability** no separador **Security** deste repositório, utiliza esse canal privado. Se essa opção não estiver disponível, contacta o proprietário através do perfil GitHub:

https://github.com/smpsandro1239

Inclui, sempre que possível:

- uma descrição objetiva do problema;
- passos mínimos para reproduzir;
- impacto e condições necessárias;
- versão, commit ou ambiente afetado;
- uma proposta de mitigação, se existir.

Agradeço a divulgação responsável e a oportunidade de analisar o problema antes de qualquer publicação pública.

## Âmbito

Este repositório é um portefólio estático. Não introduzas segredos, chaves privadas, tokens ou credenciais nos ficheiros publicados. As integrações com serviços externos devem utilizar apenas dados públicos e permissões mínimas.
